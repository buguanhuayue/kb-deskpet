# DESIGN · 知识小助（桌宠）使用说明

## Step 1 需求对齐（由上下文推定，无硬阻塞，不打断用户）

| 维度 | 结论 |
|---|---|
| 主题 | 知识小助桌面客户端（桌宠）使用说明，内容源 `docs/17-桌宠使用说明.md` |
| 目标 | 让员工独立完成 安装 → 登录 → 提问 → 存资料 → 看结果 → 更新，并避开高频坑 |
| 受众 | 普通员工（不懂技术）；附录性内容仅一处面向管理员 |
| 场合 | 内部培训 / 新人自学，可投屏也可单页阅读 |
| 调性 | 清晰、克制、可照做；不写卖点式形容词 |
| 页数 | 14 页。理由：覆盖 6 个核心动作 + 2 个最易错点，每页只讲一件事；低于 10 页会挤成文字墙，高于 16 页不适合「总结」 |

## 全局视觉约定

### ① 画布与安全区
- 1280×720；`padding: 60px` 四周，内容区 1160×600
- 内容页固定骨架：标题行（44px）→ 12px → 1px 贯通细线 → 28px → 内容区（515px）
- 页脚：绝对定位 `bottom: 30`（顶边 y=670），左右各 60px 内缩，14px
- 封面 / 结尾页不加页脚

### ② 配色（general 场景 · 科技蓝 #1，全篇只用这一套）
| 槽位 | Hex | 用途 |
|---|---|---|
| 主色 | `#2563EB` | 顶条、编号块、流程节点、主按钮 |
| 辅色 | `#06B6D4` | 第二序列、状态高亮、浅描边 |
| 强调色 | `#F59E0B` | 巨型数字、唯一警示标注（≤10% 面积） |
| 底色 | `#FFFFFF` | 页面背景 |
| 浅底 | `#EFF6FF` / `#F8FAFC` | 卡片底（每页 ≤ 2 个） |
| 分隔线 | `#E2E8F0` | 1px 贯通细线 |
| 正文色 | `#1E293B` | 主文字 |
| 弱化色 | `#64748B` | 注释、页码 |

### ③ 字体系统
- 中文：**雅黑**；西文：**Arial**（全篇仅这两族，禁苹方/腾讯体）
- 阶梯：封面主标 76 / 巨型数字 104 / 页面主标 34 / 卡片小标 24 / 正文 18–20 / 页脚 14
- 同页「字体+字号+字重」组合 ≤ 4 种；正文行高 1.5

### ④ 视觉母题
- 标题下 1px 贯通细线（`#E2E8F0`），全篇内容页复用
- 编号块统一：主色底 / 白字 / 圆角 8px / 32×32
- 圆角档位全篇统一 **8px**

### ⑤ 配图策略（关键决策）
**全篇不使用生成式插图**。这是软件操作手册，AI 生成的产品界面会与真实 UI 不符，反而误导。所有视觉用内联 SVG + Box 画结构化示意：窗口轮廓、流程链、状态条、对比分区。L1 主视觉 = 结构化 SVG 图示，全篇风格统一为「扁平线框 + 品牌蓝」。

## 节奏预算
- Hero 页：P1 封面、P7「两步原则」、P14 结尾 = 3/14 ≈ 21%
- 相邻页版式不重复；非对称版式 ≥ 40%
- 每页至少一个视觉锚点（大数字 / 大图示 / 深色块）

## 内容事实边界（写页面时逐条遵守）
- 拖进来只是暂存，必须点「存入」；「松手就入库」是旧提示语
- `⌘⇧U` 未注册为全局快捷键；无系统托盘；无「关闭到托盘」
- 右键桌宠 = 显隐面板，不是功能菜单
- 上传：50MB / 500 项 / 递归 8 层 / 串行；解析约 5 分钟超时不判失败
- 检索范围含只读共享库，存入下拉只列可写库
- 账号/空间调整后必须「完全退出应用 → 重新登录」
- v0.8.21 为当前正式版；macOS 只有 aarch64 包
- 不写浏览器地址 / 访问口令（那是旧网页版）
