# 15 · 测试用例与执行报告

> 面向：测试、验收人、接手维护的人。
> 用途：把"测过什么、没测什么"写成可复查的清单。**未执行的用例比失败的用例更危险**，
> 因为它会让人误以为覆盖了。
>
> 执行环境：`192.168.1.234:9527`（Ubuntu 24.04.5 / 8C15G）｜执行期：2026-10-30 — 10-31

## 一、测试策略

| 层 | 手段 | 目的 | 现状 |
|---|---|---|---|
| 接口级 | curl / Python urllib 直调 9 个端点 | 参数、错误码、边界 | 已执行 |
| 端到端 | 上传 → 轮询 → 提问 → 核对引用 | 主链路是否真通 | 已执行 |
| 检索质量 | `POST /api/search`（不生成） | 排除生成模型干扰，单独看召回 | 已执行（2 题） |
| 权限 | 双部门双账号交叉验证 | 越权 | **未执行** |
| 非功能 | 重启、冷启动、内存、并发 | 稳定性 | 部分执行 |
| 恢复 | 备份 → 空库恢复 | 数据可靠性 | **未执行** |

**没有单元测试。** 这是一个明确的选择：P0 阶段用端到端验证换速度，
代价是回归只能靠脚本。补单元测试的前提是接口稳定，当前还在调参期。

## 十二、回归最小集

每次改代码，至少跑这 6 条（约 3 分钟），全绿才允许提交：

```bash
BASE=http://127.0.0.1:9527; TOKEN=<token>
curl -s $BASE/api/health | grep -q '"db":"ok"'            # 1 健康
curl -s -o /dev/null -w '%{http_code}' -X POST $BASE/api/query | grep -q 401   # 2 鉴权
curl -s -X POST -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"question":"住宿费的报销标准是多少？"}' $BASE/api/search | grep -q '"count"'  # 3 检索
curl -sN -X POST -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"question":"公司股权激励怎么申报？"}' $BASE/api/query | grep -q '"refused": true'  # 4 拒答
curl -sN -X POST -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"question":"住宿费的报销标准是多少？"}' $BASE/api/query | grep -q 'event: citations'  # 5 引用
docker compose ps --format '{{.Service}} {{.State}}' | grep -c running | grep -q 4  # 6 四容器
```

## 十三、结论与放行建议

### 已有证据支持的结论

- 主链路（上传→解析→切片→向量化→检索→重排→闸门→生成→引用）**真实跑通**，非纸面推演；
- 拒答闸门有效：库外问题在生成前被拦下，未调用模型；
- 引用页码与原文一致（单文档抽样）；
- 依赖故障可降级（向量停 → 关键词；重排停 → RRF）；
- 部署可复现（目标机一次 bootstrap 成功，后续修复 3 个环境问题）；
- 稳定性：14 h 连续运行、重启 12 s 自愈、冷启动 6 s。

### 不能声称的结论

- ❌ "准确率 93.5%"——这是用例通过率，不是答题准确率；
- ❌ "权限已实现"——代码在，但 7 条场景一条没测；
- ❌ "可上线"——业务验收六项全未完成；
- ❌ "数据绝对不出网"——未抓包。

### 放行建议

| 场景 | 建议 | 前置条件 |
|---|---|---|
| 内网技术试用（1–2 人） | **可以放行** | 明确告知是试用，不接受错误答案追责 |
| 部门级试点（10–30 人） | **有条件放行** | 补 TC-401~407、TC-509、TC-510 + 20 篇真实文档 |
| 全公司上线 | **暂不放行** | 上述全部 + 30 题评测 + 阈值重标 + 审计日志 |

**一句话**：这份报告证明的是"**系统会工作**"，不是"**系统够好用**"。
两者的差距，就是 M6 业务验收要补的课。
