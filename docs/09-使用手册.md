# 09 · 使用手册

> 面向：普通员工。不需要懂技术，照做就行。

## 一、打开

浏览器访问管理员给你的地址，形如：

```
http://192.168.1.234:9527
```

> 用 Chrome / Edge / Safari 新版都行。**不要用 IE**。

## 二、登录

第一次打开会让你填 **访问口令**（一段像 `9gDXhxOD81yF_Ng4YBVbzFRG86o2leMq` 的字符串）。

- 口令由管理员发给你，**一人一个，不要共用**
- 粘贴进去，点「保存」
- 浏览器会记住，下次不用再填

> 如果提示「token 无效」，找管理员重新签发。目前没有"忘记密码"功能。

## 三、传文档

两种方式，看你的界面：

**方式一：拖拽上传**
把文件从文件夹拖到页面上的虚线框里，松手，等状态变「可检索」。

**方式二：点按钮选文件**

### 能传什么

| 格式 | 支持 | 说明 |
|---|---|---|
| PDF（电子版） | ✅ | 就是能选中文字的那种 |
| PDF（扫描件 / 手机拍照） | ❌ | **传了会失败**，因为它本质是图片，系统读不出文字 |
| Word `.docx` | ❌ | 先导出成 PDF 再传 |
| Excel `.xlsx` | ❌ | 同上 |
| 纯文本 `.txt` `.md` | ✅ | |
| CSV | ✅ | 但表格结构会丢，效果一般 |

**怎么判断是扫描件**：用 PDF 阅读器打开，能用鼠标选中文字就是电子版；选不中、光标变手型拖动，就是图片型。

### 传的时候要选「谁能看」

| 选项 | 谁能看到 |
|---|---|
| **仅自己** | 只有你能看到、能搜到 |
| **本部门**（默认） | 你和同部门同事 |
| **全公司** | 所有人 |

> 拿不准就选「本部门」。传错了目前**没法在界面里改**，要找管理员处理。

### 传完之后

页面会显示状态，等它变成「可检索」才能提问：

```
上传中 → 解析中 → 切分中 → 向量化中 → 可检索 ✅
```

一篇 20 页的 PDF 大约 **1–2 分钟**。如果变成「失败」，把错误信息截图发给管理员。

## 四、提问

在输入框里正常说话就行，**不用管关键词对不对**：

| 你可以这样问 | 不用这样问 |
|---|---|
| 住宿费能报多少？ | 住宿费 报销 标准 |
| 年假能不能分开休 | 年假 分段 |
| 服务器要多久能批下来 | 服务器 申请 流程 时长 |

系统会把意思相近的段落都找出来，不要求你用原文的措辞。

### 怎么问效果更好

| 技巧 | 例子 |
|---|---|
| **说清楚是什么事**，别只给两个词 | ✅「出差住宿费一晚上最多报多少」 ❌「住宿」 |
| **一问问一件事** | ✅「年假最小单位是多久」 ❌「年假和病假和婚假分别怎么算」 |
| **用制度里可能出现的词** | 如果制度写"差旅"，问"差旅"比问"出差"更容易命中 |
| 问不到就**换个说法再问一次** | 「探亲假」→「探亲」→「回家看父母有假吗」 |

## 五、看答案

答案长这样：

```
住宿费报销标准为每晚上限五百元，超标部分自理 [1]。
```

**方括号里的 `[1]` 就是出处**，对应下面列出的第 1 条参考资料：

```
[1] 《差旅与休假制度》 第 1 页
    住宿费报销标准为每晚上限五百元，超标部分自理…
```

### 请一定做这件事：点开核对

引用是给你**验证**用的，不是装饰。涉及以下内容时，**务必点开原文看一眼**：

- 金额、比例、天数、日期
- 审批流程和权限
- "必须""禁止""不得"这类硬性规定
- 要拿去回复客户或写进汇报的内容

系统会把原文片段和页码给你，点一下就能看到原始文件的那一页。

> 为什么必须核对：系统做的是"找段落 + 组织语言"，它不会替你判断对错。
> 如果原文本身写得不清楚或者已经过期，答案也会跟着不准。

## 六、系统说"没查到"是什么意思

看到这句话：

> 知识库里没有查到相关内容。可以换个说法再问，或者把这部分资料先传上来。

意思是：**已有的文档里确实没有相关内容，系统选择不瞎猜**。

这不是故障，是这个系统最重要的特性。对比一下：

| 系统 | 你问一个它不知道的事 |
|---|---|
| 普通 AI 聊天 | 编一个听起来很合理的答案（**最危险**） |
| 本系统 | 明确告诉你没查到，并建议你上传资料 |

遇到这种情况，按顺序试：

1. **换个说法再问**（可能用词和文档差太远）
2. **确认相关文档传了没有**（可能压根没入库）
3. **确认文档状态是「可检索」**（可能还在处理或失败了）
4. **确认权限**（可能那份文档是别的部门的）
5. 都没有 → 说明这块知识确实还没进系统，找管理员补

## 七、常见问题

**Q：搜出来的东西不是我要的？**
A：先看是不是问得太宽。问"报销"会命中所有报销相关；问"出差住宿费上限"更准。

**Q：答案里引用的页码点开是空的？**
A：可能是 PDF 本身的问题（比如文件损坏），也可能是原文文件丢了。找管理员。

**Q：能不能让它帮我写一份新文件？**
A：不能。它的定位是"查已有资料并告诉你出处在哪"，不是创作工具。

**Q：能不能接着上一个问题继续问？**
A：不能。每次提问都是独立的，需要把背景再带一句。

**Q：我传的私人文档别人能看到吗？**
A：选「仅自己」就不会。但**注意**：如果文档被检索命中，其中的片段会发给生成模型
（一个外部服务）来组织语言。真正敏感的东西，先问管理员再传。

**Q：能删掉我传错的文件吗？**
A：界面上没有删除功能，需要找管理员。所以传之前确认一下标题和可见范围。

**Q：为什么有的问题回答得很长，有的很短？**
A：取决于找到的资料有多少。资料多就详细，资料少就简短——这是正常的。

**Q：答案明显错了怎么办？**
A：把问题、答案、它引用的那份文档一起发给管理员。这类反馈是改进系统最有用的输入。
